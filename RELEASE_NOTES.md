# Nocturne Notes 2.5.0 — Minimalist note editor
Windows 11 x64 · MIT · English / Russian

- Optional SQLCipher protection, three-state lock / unlock / password setup, protected recovery.
- Safe temporary drafts, pin group, improved save/recovery, search/replace and sidebar persistence.
- Same approved interface; native security hardening, pinned runtime and comprehensive regression checks.
- Nocturne Notes Setup.exe: per-user NSIS with shortcuts and .ns association.
- Nocturne Notes Portable.exe: no installation, separate permanent AppData profile.
- SHA256SUMS.txt verifies the corresponding build; unsigned EXEs may show Windows warning. Protection does not hide filenames or encrypt plaintext exports; no password reset.

## Русский
Windows 11 x64 · MIT · английский / русский

- Опциональная защита SQLCipher, трехрежимный замок / разблокировка / установка пароля, защищенное восстановление.
- Безопасные черновики, закрепление, улучшенное сохранение/восстановление, поиск/замена и сохранение боковой панели.
