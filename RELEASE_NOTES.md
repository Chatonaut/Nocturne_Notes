# Nocturne Notes 2.0.0

First stable public release for Windows 11 x64. Both Installer and Portable editions are based on the owner-accepted 2.0.0 application source.

- **Installer:** per-user NSIS setup, .ns association, Start Menu and desktop shortcuts.
- **Portable:** no installation, stable separate profile, filename without version.
- Offline .ns SQLite projects, rich text, search/replace, trash, recovery, Undo/Redo, customizable typography, focus mode, always-on-top, English/Russian and optional tray.
- SHA256SUMS.txt verifies the specific public build; unsigned EXEs may trigger a Windows publisher warning.

## Русский

Первый стабильный публичный релиз для Windows 11 x64. Обе редакции основаны на принятом владельцем коде 2.0.0.

- **Установщик:** пошаговая установка для пользователя, ассоциация .ns, ярлыки «Пуск» и рабочего стола.
- **Portable:** без установки, отдельный постоянный профиль, имя без номера версии.
- Локальные SQLite-проекты .ns, форматирование, поиск/замена, корзина, recovery, Undo/Redo, типографика, концентрация, поверх окон, английский/русский и опциональный трей.
- SHA256SUMS.txt проверяет конкретную публичную сборку; EXE без цифровой подписи могут вызвать предупреждение Windows.
