# История версий
## 2.5.0 — 27 ноября 2026
- Опциональная защита всего проекта SQLCipher, включая recovery/корзину; установка, смена, снятие, блокировка и разблокировка. Трехрежимный замок и Ctrl+Shift+L с мгновенной маской, повтором/отменой при сбое записи.
- Управляемые временные черновики Сохранить/Не сохранять/Отмена; восстановление прерванного активного независимо от restore, безопасная очистка.
- Закрепленные заметки в верхней группе с запретом перемещения/удаления; обычные копии/восстановления; адаптивное контекстное меню.
- Поминутное автосохранение 1–20, по умолчанию 1. Живой поиск проекта, компактные смещения плотных результатов, ограничение подсветки без ограничения навигации, сохранение DOM-строк, безопасный внутренний drag, атомарная пакетная замена и Unicode-поиск.
- Надежные последовательные переходы, проверенные логические копии, атомарное создание, recovery по ID файла, отказ небезопасной замены жестких ссылок, откат панели и сохранение между сеансами, очищенный браузерный импорт/экспорт. Проверенные mailto; экспорт не перезаписывает проект.
- Electron 45.5.0, закрепленные SQLCipher 4.20.0 Community/OpenSSL 3.6.5, статическая нативная сборка, sandbox preload, CSP/IPC, fuses, аудит, SBOM, покрытие, реальные тесты UI/установщика/Portable.
- Согласованные оптические уточнения; дизайн сохраняется. Обе x64 редакции: Nocturne Notes Setup.exe / Nocturne Notes Portable.exe, отдельные постоянные профили, описание Minimalist note editor.

## 2.0.0 — 24 ноября 2026
Первый публичный стабильный выпуск: NSIS/Portable, отдельная иконка ярлыка «Пуск» и постоянный профиль Portable, EN/RU, опциональный трей, локальные SQLite-заметки, форматирование, поиск/замена, recovery, корзина, ограниченный undo, концентрация и поверх окон.
