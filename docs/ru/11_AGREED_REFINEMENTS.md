# Согласованные уточнения — итоговая 2.5.0
- Точный принятый интерфейс, оригинальная графика и дискета; форма, восемь зон resize и оптические позиции. Подменю защиты текстовое, контекстное меню адаптивное, F2 действует без печати в меню. Симметричный зазор 1 px; текст кнопок диалогов поднят на 1 px; замок заблокированного заголовка опущен на 1 px; без принудительных переносов и точек в конце описаний.
- Верхняя фиксированная группа закрепленных; новые в конец; открепленная первая обычная; перемещение/удаление запрещены до открепления; копия/восстановление обычные; разделитель 1 px только между видимыми группами.
- Обычный замок открывает установку пароля; защищенный открытый скрывает и сохраняет; заблокированный спрашивает пароль. Ctrl+Shift+L также в концентрации. Одинаковый вид, без автоблокировки. Минимум 8 кодовых точек Unicode.
- Черновики Сохранить/Отказ/Отмена; очистка только безопасно управляемых файлов, прерванный активный восстанавливается даже при отключенном restore. Трей не выход. Автосохранение 1–20 целых минут, по умолчанию 1; независимый recovery 450 мс.
- Текущий маркер .ns сохраняется, без старой совместимости/миграции; атомарное создание заметки, recovery по ID, отказ замены при нескольких жестких ссылках, очищенный браузерный просмотр, откат настроек. Без иных изменений функций.
- Имена Setup/Portable без версии; метаданные 2.5.0; описание Minimalist note editor; отдельный постоянный профиль и AUMID Portable; не удалять существующие данные. Английский по умолчанию/русский; трей выключен.
- Стабильные сборки сохраняют функциональные проверки, безопасность и упаковку, без повторных расширенных нагрузочных/сравнительных тестов. EN/RU одинаково актуальны; приватная история закрыта; только реальные публичные скриншоты и утвержденный логотип.
