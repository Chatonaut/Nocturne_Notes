# Согласованные уточнения

Финальные решения заменяют устаревшие промежуточные варианты:
- Стабильная 2.0.0; установщик с номером версии, Portable без номера в имени.
- Английский по умолчанию, полноценный русский интерфейс; пользовательский текст не переводится. Язык в последнем разделе «Приложение».
- Заголовок «Редактор» возвращен наверх, без дополнительных 12 px. Отступы, ширина, кнопки слайдеров и переключатели сохранены.
- Опциональный трей с оригинальным логотипом и нативным локализованным меню «Открыть Nocturne Notes» / «Выход». Без автозапуска. Крестик сохраняет и скрывает только при включении; обычное сворачивание неизменно.
- Обычный ICO неизменен, отдельная увеличенная иконка только ярлыку «Пуск»; оригиналы сохраняются.
- Сессионная история 50 шагов/64 МиБ, дублирование, корзина проекта, концентрация и поверх окон реализованы. Другие планируемые функции не включены.
- Дискета точно как принята; сохранять оптические центры кнопок. Не менять запуск ради внешнего вида или диагностического времени.
- Публичный README и документация: английский основной, равноценный русский; история разработки остается приватной.
