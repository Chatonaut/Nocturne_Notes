# Контроль качества — 2.5.0
Только синтетические изолированные проекты/профили. Браузерный просмотр не заменяет настоящее Windows-приложение. Стабильные сборки сохраняют все необходимые функциональные проверки, безопасность и упаковку; не повторяют нагрузочные и сравнительные замеры замороженного кода.

| Область | Приемка |
|---|---|
| Код | 34 проверенных хеша объектов; неизменный lockfile, визуальный эталон и графика, lint/типы |

| Хранение | Текущий маркер, транзакции обычных/защищенных проектов, атомарное создание, отказ чужой БД/небезопасной замены, эксклюзивная блокировка, изоляция псевдонимов и копий, fallback inode=0, откат hot journal, recovery и защита |
| UI | Настоящая геометрия, минимум 740×480, четные/нечетные ширины, восемь зон resize, настройки, диалоги, клавиши, EN/RU, концентрация, трей, индикаторы |

| Сеть | В стандартном сеансе не замечено HTTP/WebSocket-запросов приложения; словари и пути ОС отдельно |

Окончательная приемочная проверка включала 86/86 модульных тестов, 60 чередующихся сравнительных нагрузочных сессий и все обязательные проверки CI. Сценарии расширенных тестов сохранены для отдельного запуска. Покрытие относится к инструментированным файлам, не всему C++/Electron/UI. Записывать фактические доказательства, а не предположения. Важны ручные проверки на доступных DPI/фонах, реальном оборудовании и обеих редакциях. Не ослаблять упавшие проверки ради зеленого CI. См. [риски](10_RISKS_AND_DECISIONS.md).
