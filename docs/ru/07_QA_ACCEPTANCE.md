# Контроль качества

## Принятая база 2.0.0 (24 ноября 2026)
Владелец вручную принял обе редакции. Исходный CI успешно завершен: 40/40 модульных тестов, дизайн-контракт, реальный Electron UI, три чередующихся прогона производительности, упаковка/ASAR/локали, PE-иконки, установка для пользователя, фактические цели и иконки ярлыков, команда .ns в реестре, первый кадр и удаление с сохранением настроек. Тест трея подтвердил сохранение и скрытие, возврат с Undo, обычное сворачивание, перевод меню, выключение/включение и сохранение при выходе.

## Повторять для будущих релизов
1. Замороженные файлы и утвержденные ресурсы; npm ci, npm test, npm run test:ui. Не подменять desktop-тест браузерным.
2. Минимум 740×480, обычное и развернутое окно, четные/нечетные ширины, восемь направлений resize, DPI 100/125/150/200% при наличии, прозрачные углы на контрастных обоях, отсутствие вспышки запуска.
3. Обрезка заголовков и подсказка, положение кнопок 36 px, концентрация/поверх окон/история, скрытие и drag панели, форматирование и нативное меню.
4. Все настройки: EN по умолчанию, живой RU/EN, сохранение языка без изменения заметок, горизонтальные слайдеры и семь доступных шрифтов, нижний раздел «Приложение» с правильными отступами, трей выключен; отмена не применяет.
5. Создание/открытие/сохранение/копия проектов, старый маркер, отклонение чужой БД, длинный форматированный текст, дублирование, корзина/возврат/очистка, защита последней заметки, порядок, поиск/замена в обеих областях, Undo/Redo, экспорт и recovery после сбоя. Использовать копии.
6. Трей: включение создает фирменный значок и подсказку; клик/«Открыть» возвращают, обычное сворачивание сохранено, закрытие сохраняет и скрывает, «Выход» сохраняет и завершает; ошибка сохранения не скрывает; выключение удаляет значок.
7. Обе EXE, ровно две локали .pak и ожидаемый ASAR; основные иконки, заполнение только «Пуск», ассоциация .ns, установка/обновление/удаление на одноразовой Windows, сохранение проекта и настроек. Portable отдельный постоянный профиль; имя без версии.
8. Сравнивать производительность с принятой базой при наличии; отличать внутренний запуск от распаковки launcher, не обещать скорость.
9. Записать суммы и результаты. Регрессия функций, данных или дизайна блокирует релиз. Реальное оборудование и внешний вид Windows требуют приемки владельцем.
