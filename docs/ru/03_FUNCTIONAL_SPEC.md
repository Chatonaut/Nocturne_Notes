# Функциональная спецификация

## Проекты и заметки
При первом запуске создается локальный черновик с одной пустой заметкой. «Новый проект» создает черновик; «Открыть» — нативный выбор .ns; «Недавние» — до восьми реально существующих файлов, без черновиков. «Сохранить» пишет существующий проект; для черновика — «Сохранить как». «Сохранить как» копирует целую закрытую SQLite перед сменой пути. Заголовок проекта — имя без расширения (для черновика «Новый проект»). Пользовательские заголовки не переводятся при смене языка.

Создание, переименование (F2), дублирование, выбор, сортировка перетаскиванием и перенос в корзину проекта. Последнюю активную заметку удалить нельзя. В корзине можно восстановить и окончательно удалить заметки. Копия вставляется после оригинала с локализованным суффиксом. Ограничение заголовка 250 символов, HTML текста — 5 000 000 символов.

## Редактор и поиск
Форматирование: жирный, курсив, подчеркивание, зачеркивание, H1–H5, нумерованные и маркированные списки, ссылки, 35 цветов. Панель выделения отражает реальное форматирование. Очистка вставляемой/отображаемой разметки; нативное темное контекстное меню редактирования и подсказок орфографии при наличии словарей. Поиск по заголовку и тексту активной заметки или всего проекта. Enter/Shift+Enter — навигация. Замена только в выбранной области и текстовых узлах, без повреждения нетронутого форматирования. Поиск временно расширяет узкую панель минимум до 220 px и возвращает ее ширину. Экспорт отдельной заметки в TXT, HTML или базовый Markdown.

Сессионные Undo/Redo для заголовка и HTML: 50 логических шагов на заметку, общий приблизительный лимит 64 МиБ; история не записывается на диск. Концентрация F11/Esc и поверх окон Ctrl+Shift+T — независимые оконные функции.

## Настройки
| Настройка | Диапазон/варианты | По умолчанию |
|---|---|---|
| Шрифт | Segoe UI Variable, Arial, Calibri, Verdana, Tahoma, Georgia, Times New Roman | Segoe UI Variable |
| Заголовок | 15–35 px | 20 |
| Текст | 10–35 px | 17 |
| Межстрочный интервал | 1,0–2,0, шаг 0,1 | 1,1 |
| Панель форматирования | вкл/выкл | вкл |
| Индикаторы сохранения | вкл/выкл | вкл |
| Орфография | английский/русский, доступные словари | выкл |
| Автосохранение после ввода | 1/3/5 мин | 1 мин |
| Восстановление проекта | вкл/выкл | вкл |
| Язык | английский/русский | английский |
| Сворачивание в трей при закрытии | вкл/выкл | выкл |

Изменения применяются только по «Сохранить»; переключатели реагируют на собственный контрол. Язык обновляет интерфейс, подсказки, меню, диалоги, ошибки и нативный трей без изменения текста заметок и текущей истории Undo. Системные контролы диалогов Windows могут следовать языку ОС. При включенном трее закрытие сохраняет и скрывает; левый клик/«Открыть» восстанавливает, «Выход» сохраняет и завершает. Обычное сворачивание без изменений. Ошибка сохранения препятствует скрытию и выходу.

## Сохранение
Статус активной заметки: зеленый — сохранено, желтый — ожидает, красный — ошибка. Атомарный recovery-черновик пишется примерно через 450 мс после ввода; успешная запись проекта удаляет его. Принудительная запись при смене заметки/проекта, потере фокуса, скрытии и закрытии. Восстановление доступного прошлого файла и геометрии; отсутствующие или некорректные файлы не перезаписывать молча. Настройки и recovery находятся вне .ns.
