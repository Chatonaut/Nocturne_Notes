# План работ и поддержка

Объем приложения 2.0.0 завершен и вручную принят. Сохранять принятый снимок. Дистрибуция: двуязычная документация, чистый публичный код, GitHub Release с проверенными Installer и Portable, SHA-256 и настоящие скриншоты. Приватный репозиторий сохраняет историю разработки и исходные принятые артефакты; публичный начинается с чистого снимка релиза. Не переносить приватные обсуждения и экспериментальную историю в открытый код.

При поддержке: оформить ограниченную задачу, отдельную ветку, защищать данные/формат и дизайн, тестировать обе редакции, получить приемку владельца, затем обновлять версию, EN/RU-документы и релиз. Не добавлять функции без согласования. Удалять только замененные артефакты после проверки доступности стабильных; не переписывать историю Git.
