# Сопровождение
Сохранять утвержденный UI, формат, закрепленную среду и графику. Ограничивать объем изменений, тестировать на синтетических данных, обновлять EN/RU, соблюдать [сборку](06_BUILD_GITHUB.md) и [QA](07_QA_ACCEPTANCE.md). Не ослаблять проверки и не перезаписывать файлы релиза. Расширенные замеры — отдельная целевая проверка, не повтор для неизменного выпуска. Проверять [Releases](https://github.com/Chatonaut/Nocturne_Notes/releases).
