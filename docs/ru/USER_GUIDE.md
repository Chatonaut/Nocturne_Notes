# Руководство пользователя

## Установка или запуск
Скачайте один из двух вариантов Windows x64 из [Releases](https://github.com/Chatonaut/Nocturne_Notes/releases). Setup устанавливает для пользователя с выбором каталога, ярлыками и ассоциацией .ns. Portable запускается без установки, но хранит настройки и recovery в AppData. Проверьте SHA-256 через Get-FileHash. EXE не имеют цифровой подписи; Windows может предупредить об издателе. Скачивайте только из официального репозитория и проверяйте сумму.

## Работа с проектами
Начните с пустой заметки; создавайте заметки кнопкой +, называйте, форматируйте и перетаскивайте для сортировки. «Сохранить»/«Сохранить как» позволяет выбрать файл .ns. Проект — одна локальная SQLite со всеми заметками и корзиной. Копируйте закрытый .ns для резервной копии или переноса. Старые проекты открываются напрямую или сначала сделайте копию. Правая кнопка по заметке открывает доступные действия; удаленные заметки в корзине проекта. Окончательное удаление из корзины не отменяется сессионным Undo.

## Редактор и настройки
Выделяйте текст для форматирования; ищите и заменяйте в заметке или всем проекте. Экспорт текущей заметки в TXT, HTML или MD. В настройках выбираются шрифт, размеры заголовка/текста, интервал, автосохранение, индикаторы, орфография и восстановление. Раздел «Приложение» — язык и трей по выбору. «Сохранить» применяет настройки. Английский по умолчанию. При включенном трее крестик сохраняет и скрывает; клик по фирменному значку возвращает окно, правая кнопка — «Выход». Windows может поместить значок в скрытую область трея.

## Горячие клавиши
| Клавиши | Действие |
|---|---|
| Ctrl+N / Ctrl+Shift+N | Новая заметка / проект |
| Ctrl+O | Открыть проект |
| Ctrl+S / Ctrl+Shift+S | Сохранить / сохранить как |
| Ctrl+F / Ctrl+H | Поиск / замена |
| Enter / Shift+Enter в поиске | Следующее / предыдущее совпадение |
| Ctrl+Z / Ctrl+Y или Ctrl+Shift+Z | Отменить / повторить |
| Ctrl+B / Ctrl+I / Ctrl+U | Жирный / курсив / подчеркивание |
| Ctrl+Backslash | Показать/скрыть список |
| F2 | Переименовать активную заметку |
| F11 / Esc | Концентрация / выход из нее |
| Ctrl+Shift+T | Поверх окон |

Удаление приложения не удаляет проекты .ns и настройки. Файлы локальные и нешифрованные; защищайте чувствительные записи правами Windows и резервными копиями. Без аккаунта и облака.
