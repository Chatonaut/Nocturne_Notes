# Руководство пользователя

## Установка или запуск
Скачайте один из двух вариантов Windows x64 из [Releases](https://github.com/Chatonaut/Nocturne_Notes/releases). Setup устанавливает для пользователя с выбором каталога, ярлыками и ассоциацией .ns. Portable запускается без установки, но хранит настройки и recovery в AppData. Проверьте SHA-256 через Get-FileHash. EXE не имеют цифровой подписи; Windows может предупредить об издателе. Скачивайте только из официального репозитория и проверяйте сумму.

## Работа с проектами
Начните с пустой заметки; создавайте заметки кнопкой +, называйте, форматируйте и перетаскивайте для сортировки. «Сохранить»/«Сохранить как» позволяет выбрать файл .ns. Проект — одна локальная БД SQLite или защищенная SQLCipher со всеми заметками и корзиной. Копируйте закрытый .ns для резервной копии или переноса. Правая кнопка по заметке открывает доступные действия; удаленные заметки в корзине проекта. Окончательное удаление из корзины не отменяется сессионным Undo.

## Редактор и настройки
Выделяйте текст для форматирования; ищите и заменяйте в заметке или всем проекте. Экспорт текущей заметки в TXT, HTML или MD. В настройках выбираются шрифт, размеры заголовка/текста, интервал, автосохранение, индикаторы, орфография и восстановление. Раздел «Приложение» — язык и трей по выбору. «Сохранить» применяет настройки. Английский по умолчанию. При включенном трее крестик сохраняет и скрывает; клик по фирменному значку возвращает окно, правая кнопка — «Выход». Windows может поместить значок в скрытую область трея.

## Горячие клавиши
| Клавиши | Действие |
|---|---|
| Ctrl+N / Ctrl+Shift+N | Новая заметка / проект |
| Ctrl+O | Открыть проект |
| Ctrl+S / Ctrl+Shift+S | Сохранить / сохранить как |
| Ctrl+F / Ctrl+H | Поиск / замена |
| Enter / Shift+Enter в поиске | Следующее / предыдущее совпадение |
| Ctrl+Z / Ctrl+Y или Ctrl+Shift+Z | Отменить / повторить |
| Ctrl+B / Ctrl+I / Ctrl+U | Жирный / курсив / подчеркивание |
| Ctrl+Backslash | Показать/скрыть список |
| F2 | Переименовать активную заметку |
| F11 / Esc | Концентрация / выход из нее |
| Ctrl+Shift+T | Поверх окон |
| Ctrl+Shift+L | Установить пароль / заблокировать / разблокировать |

Удаление приложения не удаляет проекты .ns и настройки. Обычные проекты не зашифрованы; для чувствительных записей используйте защиту проекта, права доступа Windows и резервные копии. Без аккаунта и облака.

## Защита паролем
Сделайте резервную копию перед изменением защиты. В меню «Защита проекта» выберите «Установить пароль», введите и подтвердите пароль (не менее 8 кодовых точек Unicode); защищенный проект спрашивает пароль при открытии. Блокировка явная: «Заблокировать»; «Разблокировать» требует пароль. Сворачивание, скрытие/возврат из трея и переключение заметок не запрашивают пароль повторно в открытом сеансе. «Изменить пароль» и «Удалить пароль» требуют текущий пароль. Смена и снятие защиты в том же меню с текущим паролем. Берегите резервную копию и пароль: сброса нет. Имена файлов видны; прежние открытые копии и экспорт TXT/HTML/MD не шифруются (при экспорте предупреждение). После закрытия и повторного открытия нужен пароль; не рассчитывайте на автоблокировку при сворачивании или потере фокуса. Не редактируйте один проект одновременно из двух редакций.

### Временные проекты и закрепление (2.5)
«Сохранить» или «Сохранить как» выбирает постоянное место. Для непустого безымянного проекта при выходе или смене проекта предлагается «Сохранить / Не сохранять / Отмена». Отказ окончательно удаляет черновик после успешного перехода; отмена сохраняет его. Закрытие в трей не удаляет. После прерванного сеанса активный черновик восстанавливается и при отключенном обычном восстановлении. Старые управляемые черновики очищаются при запуске. В контекстном меню заметки «Закрепить» (закладка) перемещает ее в фиксированную верхнюю группу и запрещает удаление; новые добавляются в конец группы, «Открепить» помещает заметку первой среди обычных. Обычные свободно сортируются ниже закрепленных. Редактирование и дублирование доступны; копия не закреплена. Метаданные следуют за проектом, в том числе защищенным. 

Замок верхней панели или Ctrl+Shift+L скрывает и блокирует открытый защищенный проект, в том числе в режиме концентрации. Изменения записываются до блокировки. Если запись не удалась, содержимое остается скрытым; повторите блокировку или явно отмените для возврата. Для разблокировки нажмите ту же кнопку замка, Ctrl+Shift+L или пункт меню защиты; в любом случае нужен пароль. В редакторе заблокированного проекта только замок и «Проект заблокирован». Ползунок автосохранения от 1 до 20 минут с шагом 1 минута, по умолчанию 1; аварийное восстановление независимо.

Замок верхней панели и Ctrl+Shift+L открывают установку пароля и для обычного проекта; отмена ничего не меняет. После успешной установки проект открыт; повторное нажатие блокирует. Яркость кнопки одинакова во всех состояниях защиты.


### Проверка скачанного файла
В PowerShell выполните `Get-FileHash -Algorithm SHA256 'Nocturne Notes Setup.exe'` (или `Nocturne Notes Portable.exe`) и сравните с соответствующей строкой `SHA256SUMS.txt` релиза. Настройки установленной редакции — `%APPDATA%/Nocturne Notes`, Portable — отдельный `%APPDATA%/Nocturne Notes Portable`. Portable не регистрирует ассоциацию .ns и не устанавливает ярлыки автоматически. Закройте другую редакцию перед открытием того же проекта.
