# Риски и решения

| Тема | Решение / ограничение |
|---|---|
| Прозрачное нативное окно | Сохранить принятый alpha-режим и восемь зон; вариации GPU/DPI требуют ручной проверки. |
| Безопасность данных | Локальная SQLite, атомарный recovery, запись перед сменой/закрытием; копии .ns; без шифрования. |
| Профили | Установка сохраняет идентичность; Portable отдельный постоянный AppData; экспериментальные профили не мигрируют. |
| Несколько экземпляров | Не считать одновременное редактирование одного проекта безопасным; закрыть другой экземпляр. |
| Трей | По выбору, сохраняет renderer/сессию; нативный «Выход» завершает, без автозапуска Windows. |
| Подпись | Нет настроенных сертификатов; Windows может показать SmartScreen. SHA-256 подтверждает целостность, не личность издателя. |
| Орфография | Доступность словарей зависит от Electron/ОС, отдельно от двух UI-локалей. |
| Формат | Старый маркер принимается, корзина опциональна, схема без изменений без миграции. |
| Preview | Браузерная демонстрация не является реализацией SQLite/Windows. |
| История | Undo ограничен памятью; не постоянная история версий. |
| Экспорт | Markdown базовый, не полностью сохраняющий богатое форматирование. |
| Производительность | CI-бенчмарк синтетический, без гарантии времени; Portable распаковывается до метрик запуска. |
| Безопасность | Нет функций синхронизации/телеметрии; внешние ссылки в браузере, аудит безопасности не заявлен. |
| Релиз | Публичная пересборка идентичного кода не гарантирует побайтового совпадения с принятыми приватными EXE; публиковать соответствующие суммы. |

Сохранять идентичность приложения и фиксированные зависимости. Графику и дизайн менять только после согласования.
