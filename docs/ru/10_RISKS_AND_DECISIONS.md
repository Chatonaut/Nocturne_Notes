# Риски и решения — 2.5.0
| Тема | Решение / ограничение |
|---|---|
| UI | Замороженная нативная оболочка; GPU, DPI, композитор Windows требуют проверки на реальном оборудовании. |
| Хранение | Эксклюзивная блокировка SQLite, транзакции и recovery; закрывать перед копированием/переносом; резервировать .ns. Не редактировать одновременно. |
| Восстановление | Точный ID файла; канонический fallback при inode=0 для файла с одной ссылкой не отслеживает произвольное переименование. Внешнее удаление/замена может оставить sidecar. Нет общего recovery редакций. Реальные FAT/exFAT и физическое отключение питания не полностью проверены. |
| Защита | SQLCipher по желанию; минимум 8 кодовых точек Unicode, лучше длинный уникальный пароль. Сброса нет. Имена, буфер обмена, открытый экспорт, прежние копии, снимки, файл подкачки вне защиты. Без безопасного стирания. |
| Замок | Явный, без автоблокировки трея/сворачивания. Сбой записи оставляет маску до повтора/отмены. |
| Профили | Отдельные постоянные профили; без автоматической миграции или удаления существующих. |
| Подпись | EXE без подписи могут вызвать SmartScreen; SHA-256 подтверждает целостность, не издателя. |
| Словари | Опциональные словари могут загружаться; системные пути вне стандартного перехвата сети. Нет аккаунта/синхронизации/телеметрии как функции. |
| История/экспорт | Undo 50 шагов на заметку, общий приблизительный лимит 64 МиБ, только сеанс. Markdown базовый, не без потерь. |
| Безопасность | Закрепленный аудит, sandbox, CSP, проверяемый IPC, ASAR/fuses; не сертификация и не гарантия отсутствия уязвимостей. Заключение CLI CVE условно. Четыре deprecated транзитивных зависимости только сборки оставлены до безопасного обновления. |
| Скорость | Синтетические CI-замеры варьируются; сумма рабочих наборов может удваивать общие страницы; 60 коротких сессий не доказывают отсутствие длительных утечек. Распаковка Portable входит в общий запуск. |
| Релиз | Независимые бинарники могут отличаться; проверять соответствующие хеши и происхождение кода. |
| Объем | Старые миграции/совместимость не требуются. Без новой функции или изменения кода без явного согласия. |

Не ослаблять проверки, не менять замороженное поведение, не удалять данные и не давать неподтвержденных гарантий.
