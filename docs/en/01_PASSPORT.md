No old-version compatibility or migration work. Current format and existing data must remain protected.

Both editions use the same application source and independent profiles. Installer is per-user; Portable is no-install, not a fully self-contained profile. See [user guide](USER_GUIDE.md) and [limitations](10_RISKS_AND_DECISIONS.md).
